## English (en-US, default)

**Search terms** (7 max): `transmission` · `torrent` · `magnet` · `bittorrent` · `remote` · `nas` · `seedbox`

**Description**

```
Transmission Remote puts your Transmission BitTorrent server in the Edge toolbar. Check what your home server, NAS or seedbox is doing and add new torrents without opening the web interface.

SEE EVERYTHING AT A GLANCE
• Total download and upload speed
• Every torrent with progress, peers, ETA, ratio and errors
• Filters: All, Active, Downloading, Seeding, Paused
• Start, pause or remove a torrent (optionally with its data) in one click
• The toolbar badge counts active downloads and turns red on errors

ADD TORRENTS IN ONE CLICK
• Click a .torrent or magnet link on any site and an Add dialog opens instead of a download
• See the name, size, tracker, comment and the full file list before adding
• Untick the files you don't want
• Choose the download folder and see the free space left
• Add it started or paused
• Also works for download links that don't end in .torrent and for sites that need you to be logged in
• Right-click a .torrent link and pick "Add to Transmission…"
• Hold Ctrl or Shift while clicking to let Edge handle the link normally

SAFE FOLDERS
You decide which folders inside Transmission's download folder torrents may be saved to. The add dialog only offers those, so nothing ends up anywhere else on your server.

PRIVATE
No account, no analytics, no ads. The extension talks only to your own Transmission server. Settings sync between your PCs through your Edge profile.

7 LANGUAGES
English, Deutsch, Español, Français, Português (Brasil), Русский, 简体中文. Light and dark theme.

SETUP
Enter your server's address (for example 192.168.1.10), add a username and password if you use one, and press Test connection. Requires a Transmission server with remote access (RPC) turned on.

About permissions: "Read and change all your data on all websites" is needed to notice clicks on torrent links on any page and to download .torrent files from the site that hosts them. Page content is never read or collected.

Transmission Remote is an independent project and is not affiliated with the Transmission project.
```
